# Build a reusable known-answer validation suite

A known-answer suite checks separate layers of a workflow: graph construction,
signal alignment, an estimator's numerical convention, and stochastic
reproducibility. Passing it detects implementation regressions but does not
establish empirical model adequacy.

## Input

Store the expected values, tolerances, package version, and seeds beside the
analysis. Use exact assertions for discrete invariants and tolerance-based
comparisons for floating-point quantities.

## Worked example

```python
# cookbook: test
import json
from importlib.metadata import version

import numpy as np

from fitness_landscape.analysis import (
    calculate_epistasis_walsh,
    calculate_ruggedness_dirichlet_energy,
    find_greedy_accessible_paths,
)
from fitness_landscape.models import create_rmf_landscape

landscape = create_rmf_landscape(N=3, slope=2.0, sigma=0.0, optimum=[0, 0, 0])
signal = landscape.get_signal()
distances = np.array([sum(sequence.to_array()) for sequence in landscape.sequences])

graph_checks = {
    "nodes": landscape.graph.number_of_nodes(),
    "edges": landscape.graph.number_of_edges(),
    "degrees": sorted(dict(landscape.graph.degree()).values()),
}
epistasis = calculate_epistasis_walsh(landscape, order=3)
energy = calculate_ruggedness_dirichlet_energy(landscape)
paths = find_greedy_accessible_paths(
    landscape, landscape.sequences[-1], landscape.sequences[0]
)

assert graph_checks == {"nodes": 8, "edges": 12, "degrees": [3] * 8}
np.testing.assert_allclose(signal, -2.0 * distances)
assert all(
    abs(value) < 1e-12
    for order in (2, 3)
    for value in epistasis["by_order"][order].values()
)
np.testing.assert_allclose(energy["global_dirichlet_energy"], 48.0)
assert paths["path_count"] == 6

manifest = {
    "package": "landscapy",
    "version": version("landscapy"),
    "model": {"name": "rmf", "N": 3, "slope": 2.0, "sigma": 0.0},
    "checks": graph_checks | {"energy": energy["global_dirichlet_energy"]},
    "tolerances": {"absolute": 1e-12, "relative": 1e-9},
}
assert json.loads(json.dumps(manifest))["model"]["sigma"] == 0.0
print(manifest)
```

For stochastic functions, add at least two checks: the same seed reproduces the
same result, and independently chosen seeds generate the intended variation.
Run empirical analyses only after these controls pass.

## Common failures

- One end-to-end number is used without localizing graph, signal, or estimator errors.
- Floating-point outputs are checked with exact equality or undocumented tolerances.
- The expected answer is regenerated by the same function under test.
- Seed reproducibility is confused with independent replication.
- Passing synthetic controls is treated as validation of an empirical conclusion.
