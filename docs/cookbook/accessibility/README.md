# Adaptive walks, accessibility, basins, and neutrality

These recipes ask topographic and design-accessibility questions on the
observed graph. They describe which represented mutational routes connect
genotypes under declared adjacency, fitness-gradient, tie, and walk rules.
Their conclusions are conditional on graph construction and observed support.
